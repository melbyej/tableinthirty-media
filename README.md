# Table in Thirty media

Public video files for the @tableinthirty Instagram/Facebook page, served to Buffer via jsDelivr:

`https://cdn.jsdelivr.net/gh/melbyej/tableinthirty-media@<commit-sha>/<path>.mp4`

- `week1/` – week 1 Reels (1080x1920, H.264/AAC, faststart)
- `crosspromo/` – J's Recipays cross-promo Reels

Keep every file under 20 MB (jsDelivr limit). Always pin URLs to a commit SHA.
